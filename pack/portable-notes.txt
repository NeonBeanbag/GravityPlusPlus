Gravity++ 免安装版使用说明
=====================================

这是什么
    把变砖的 MEIZU Gravity（A8）音响在纯 Windows 下救活并日常使用的小工具：
    重新配网 + 托盘面板（正在播放 / 音量 / 音效 / 设备连接）。
    免安装，不需要装 .NET、不需要装任何东西，解压即可用。

三步跑起来
    1. 右键这个 zip →「全部解压」（或用 Bandizip / 7-Zip 的「解压到 GravityPP…」）。
       不要只在压缩软件里双击打开，要先解压成一个文件夹。
    2. 打开解压出来的文件夹，双击 Gravity++.exe。
    3. 屏幕右下角任务栏托盘里会出现 Gravity++ 图标。
       左键点图标 = 展开/收起面板；右键 = 菜单（含「开机自启」）。
       也可以按全局热键 Ctrl+Alt+G 呼起面板。

第一次运行如果 Windows 拦你
    这个程序没有花钱买代码签名证书，所以 Windows SmartScreen 可能弹蓝底提示
    「Windows 已保护你的电脑」。这是对所有未签名程序的正常反应，不是病毒。
    → 点提示里的「更多信息」，再点「仍要运行」。
    如果解压后双击完全没反应，右键 Gravity++.exe →「属性」→
    勾选底部的「解除锁定 / Unblock」→「确定」，再双击。

面板上怎么用
    「设备连接」这一行默认是折叠的，点开它：
      - 面板会自己通过 SSDP 找音响，不需要你填 IP。
      - 找不到时点「自检」，它会告诉你当前 Wi-Fi、网卡设置、防火墙哪一项不对。
      - 音响被重置过、连不上 Wi-Fi 时，展开「给音响配网」：
        先在音响上同时按住背面「+」和「−」两秒进入配网模式，再点发送。
        配网期间不要切换电脑的 Wi-Fi，成功后音响会自动回线。

系统要求
    Windows 10 19041（2004）或更高 / Windows 11，64 位。
    已包含全部运行库，机器上没有 .NET / Visual Studio 也能跑。
